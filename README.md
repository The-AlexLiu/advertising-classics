## 从手头的问题开始

- **准备测一批新标题**　先看 Caples 的 *Tested Advertising Methods* 比较标题写法，再读 Hopkins 的 *Scientific Advertising*，想清楚用什么回应判断胜负。[读 Hopkins 的 1923 年原书](books/scientific-advertising-1923.pdf)
- **素材点击不错，却没人记得品牌**　把几条广告的品牌名遮住，看看还剩什么共同线索。Romaniuk 的 *Building Distinctive Brand Assets* 适合用来设计识别测试。[查这本书](https://marketingscience.info/learn-with-us/books)
- **复盘时，品牌广告和促销广告共用一个七天窗口**　先读 Binet 和 Field 讨论效果如何随时间累积，再决定两类广告各看多久。[读 IPA 的研究介绍](https://ipa.co.uk/knowledge/publications-reports/the-long-and-the-short-of-it-balancing-short-and-long-term-marketing-strategies/)
- **想看中文广告的原始画面**　从《圖像與商業文化》里的近代广告入手，观察商品怎样被放进当时的生活场景。[读香港大学出版社原书](books/images-and-commercial-culture-2014.pdf)

## 选书与增补

首版保留六类问题，每类四本。广告实务专著、经典教材和有独立书目的研究专著均可收录。品牌、心理学与实验方法书，须能说明它帮助读者做哪项广告决策。后续补书优先填尚未覆盖的主题，例如广播广告、日文广告文案或户外广告设计。推荐时请附书名、作者、能核验的版本链接，以及它补上了哪一块。

各份原书的出处、版本和使用条件见[原书来源说明](books/README.md)。
